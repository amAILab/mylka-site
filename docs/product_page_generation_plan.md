# Mylco — таблица товаров и автогенерация карточек

## Идея

Не создавать вручную десятки похожих страниц. Вместо этого:

1. Заполняем таблицу товаров `data/mylco_products_template.csv`.
2. Для каждого товара выбираем тип страницы:
   - `deep_card` — полноценная продающая карточка для важных товаров/категорий;
   - `short_card` — короткая карточка для второстепенных товаров;
   - `category_landing` — посадочная под категорию;
   - `no_page` — не генерировать отдельную страницу.
3. Генератор берёт строку и собирает HTML по одному шаблону.
4. Топовые страницы дорабатываются руками после генерации.

## Минимальный набор колонок

Обязательные:
- `status` — active/draft/hidden;
- `priority` — 1 топ, 2 средний, 3 низкий;
- `page_type` — deep_card/short_card/category_landing/no_page;
- `category`;
- `product_name`;
- `slug`;
- `hero_title`;
- `short_description`;
- `main_use`;
- `key_benefits`;
- `limitations`;
- `what_to_send`;
- `seo_title`;
- `seo_description`;
- `source_url`.

## Правило качества

- Не генерировать отдельные SEO-страницы для мусорных дублей.
- Топовые товары и категории делать глубже: сценарии применения, выбор материала, FAQ, сопутствующие товары.
- Второстепенные товары можно делать короткими, но не пустыми.
- Каждая карточка должна отвечать: кому подходит, где применять, что прислать для точного подбора, какие ограничения.

## Как перенести в Google Sheets

1. Создать таблицу `Mylco product pages`.
2. Импортировать CSV `data/mylco_products_template.csv`.
3. Закрепить первую строку.
4. Ввести фильтры по `status`, `priority`, `page_type`, `category`.
5. Использовать CSV-экспорт как источник для генератора.

## Следующий шаг

Сделать скрипт `scripts/generate_product_pages.py`, который:
- читает CSV;
- пропускает `status != active` и `page_type = no_page`;
- создаёт HTML в `generated/product-pages/`;
- вставляет SEO-title/description;
- добавляет CTA на подбор материала.
