Дата: 2026-05-09  
Статус: текстовое ТЗ перед редизайном главной страницы

## 1. Цель редизайна

Переделать главную страницу Mylco не как абстрактный лендинг, а как современный e-commerce сайт материалов и оборудования, который помогает пользователю выбрать правильный материал под задачу.

Главная должна продавать:

- силиконы;
- полиуретаны;
- эпоксидные смолы;
- жидкие пластики;
- разделители, пигменты, добавки;
- вакуумные камеры и оборудование;
- комплекты под задачу;
- консультацию технолога/менеджера.

STEP 3D упоминать только как вспомогательную производственную помощь: мастер-модель, 3D-сканирование, CAD, прототип.

## 2. Позиционирование

### Главная формула

**Mylco — магазин материалов и оборудования для форм, литья, декора, прототипов и малых производств.**

### Расширенная формула

Mylco помогает выбрать и купить материалы для форм, литья и мастерских задач: силиконы, полиуретаны, смолы, жидкие пластики, разделители, пигменты и вакуумное оборудование — с консультацией технолога и подбором комплекта.

## 6. Ключевая логика сайта

Пользователь может идти двумя путями:

### Путь 1 — знает материал

Категория → товар → наличие/цена → заказ/заявка.

### Путь 2 — знает задачу

Задача → рекомендованный материал → комплект → консультация → заказ.

Главная должна сразу показывать оба пути.

## 13. Блок экспертности

### Заголовок

**Один неверный материал может испортить всю форму**

### Смысл

Материалы лучше выбирать до покупки, а не после неудачной заливки.

Пункты:

- слишком жёсткий силикон может не выпустить модель;
- без разделителя можно испортить форму;
- без вакуума останутся пузыри;
- полиуретан выбирается по нагрузке, а не только по цене;
- расход нужно считать с запасом.

CTA: **Задать вопрос технологу**

## 19. Визуальный стиль

### Нужное ощущение

Современный магазин материалов + технологическая экспертиза.

### Не нужно

- старый хобби-магазин;
- зелёный стартап-лендинг;
- сайт 3D-студии;
- абстрактные блоки без товаров;
- перегруженная шапка.

### Палитра

- фон: тёплый белый;
- текст: графитово-зелёный;
- основной акцент: глубокий зелёный;
- CTA: яркий зелёный;
- подсказки: светлая мята;
- линии: мягкий серо-зелёный.

### Фото

Нужны предметные визуалы:

- банки материалов;
- силиконовая форма;
- заливка;
- вакуумная камера;
- готовая отливка;
- рабочий стол/мастерская.

## 20. Тон текста

Спокойный экспертный.

Не писать:

> Воплотите свои мечты!

Писать:

> Подберём материал так, чтобы форма снялась, деталь получилась, а расход был понятен заранее.

Не писать:

> Огромный выбор товаров для творчества.

Писать:

> Выберите материал по задаче: форма, отливка, заливка, дегазация или комплект для мастерской.

## 21. Ограничения

- Не добавлять обучение/курсы.
- Не делать STEP 3D главным героем сайта.
- Не обещать рабочую корзину/checkout, если preview статический.
- Сохранять noindex для preview.
- Не ломать существующие ссылки категорий и товаров.
- Mobile должен быть проверен отдельно.

## 22. Критерии готовности первого редизайна

Первый экран отвечает на вопрос: «что продаём и кому помогаем?»

На главной есть два понятных входа:

- по материалу;
- по задаче.

Есть блок комплектов.

Есть мини-бриф.

Есть доверие.

STEP 3D упомянут только как вспомогательная помощь.

Mobile без горизонтального overflow.

Все CTA ведут к каталогу, подбору, заявке, телефону или почте.

## 23. Следующий шаг после утверждения

Сделать редизайн главной в одну аккуратную итерацию:

1. не переписывать весь сайт заново;
2. сохранить существующие ссылки;
3. заменить только главную структуру и стили;
4. проверить desktop/mobile;
5. оставить noindex;
6. не подключать фейковый backend.
