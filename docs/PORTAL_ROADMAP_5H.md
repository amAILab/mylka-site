# Mylco — 5-часовой план доводки preview до уровня сильного B2B-портала

Цель: сделать GitHub Pages preview не просто красивой главной, а прототипом лучшего российского портала по материалам для форм, литья, макетов и малых производств.

Ограничения:
- live `mylco.ru` не трогать;
- preview остаётся `noindex`;
- ядро — товары Mylco: силиконы, полиуретаны, смолы, пластики, вакуум, расходники;
- STEP 3D — только производственный апсейл: мастер-модель, CAD, скан, малая серия; без обучения и курсов.

## Спринт на 5 часов

### 0:00–0:40 — Карта портала и эталонная структура
- Зафиксировать портал как 4 входа: каталог, подбор по задаче, готовые комплекты, B2B-закупка.
- Убрать внутренние/preview-формулировки из видимой части.
- Добавить надкаталожную схему «задача → материал → комплект → заказ».

Результат: понятная верхняя структура, которую можно показывать партнёру.

### 0:40–1:40 — Каталог через данные
- Расширить `data/mylco_products_template.csv` до рабочей структуры.
- Добавить поля: категория, сценарий применения, Shore/вязкость/фасовка, сопутствующие товары, CTA.
- Подготовить генератор для карточек и посадочных.

Результат: база для масштабирования без ручной нарезки сотен страниц.

### 1:40–2:40 — Посадочные категории
- Усилить 4–5 ключевых разделов: силиконы, полиуретаны, смолы, вакуум, расходники.
- На каждой странице: быстрый выбор, что уточнить, сопутствующие товары, заявка.

Результат: не просто SEO-текст, а коммерческие страницы категорий.

### 2:40–3:40 — Подборщик материала и комплекта
- Сделать интерфейс «что вы делаете?» → рекомендованный материал/комплект.
- Встроить готовые сценарии: форма под гипс, прозрачная заливка, малая серия, дегазация, закупка для юрлица.

Результат: клиент быстрее отправляет осмысленную заявку.

### 3:40–4:30 — B2B-доверие и заявка
- Усилить блоки для юрлиц: счёт, документы, регулярные поставки, самовывоз/доставка.
- Сделать бриф более похожим на коммерческий запрос, а не форму обратной связи.

Результат: портал выглядит как поставщик, а не витрина.

### 4:30–5:00 — Проверка и упаковка
- Прогнать preview validation.
- Проверить мобильный первый экран, CTA, отсутствие горизонтального скролла.
- Commit/push и итоговая ссылка с `?v=`.

## Лимиты

Режим по умолчанию: нормальный — 35–45% 5h-лимита. При остатке лимита меньше часа делать только самые видимые/безопасные правки и переносить тяжёлую генерацию на следующий запуск.
