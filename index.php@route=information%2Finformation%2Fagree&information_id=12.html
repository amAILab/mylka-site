Какие данные могут понадобиться

Для обработки обращения обычно достаточно имени, контакта и описания задачи. Для B2B-запросов могут потребоваться реквизиты, адрес доставки и данные для счёта — только когда пользователь сам передаёт их для обработки запроса.

для пользователя

Как безопасно отправлять запрос

Описывайте задачу

Для подбора чаще важнее материал, форма, объём и условия работы, чем лишние личные данные.

Лучше указать:задача · материал · объём · срок

Не отправляйте лишнее

Не прикладывайте документы и персональные данные, если они не нужны на этапе консультации.

Лучше указать:минимальный контакт · вопрос · город

Проверяйте канал связи

Для рабочих запросов используйте официальные контакты страницы.

Контакты:телефон · почта · форма после запуска

Уточняйте удаление

Если запрос больше не актуален, можно попросить удалить или не использовать контактные данные.

Можно запросить:удаление · исправление · уточнение
