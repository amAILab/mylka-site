# Мылка — приватный рабочий клон сайта

Приватный репозиторий для безопасной доработки сайта до публикации.

## Цель

Улучшить сайт под продажи силикона и смежных материалов: SEO, конверсия, структура каталога, доверие, заявки, аналитика.

## Статус

- Репозиторий создан как приватный рабочий контур.
- Исходники живого сайта пока не загружены: нужен точный домен/доступ к хостингу или текущий репозиторий.
- До любых правок на боевом сайте обязательно сделать резервную копию.

## Первые направления

1. Технический аудит: домен, HTTPS, скорость, мобильная версия, robots/sitemap, ошибки.
2. Коммерческий аудит: УТП, каталог, карточки товаров, доставка/оплата, доверие, опт/B2B.
3. SEO-структура: силикон для форм, платиновый/оловянный силикон, пищевой силикон, смолы, разделители, красители, наборы.
4. Конверсия: подбор материала по задаче, калькулятор расхода, форма консультации, мессенджеры.
5. Контент: гайды, кейсы, инструкции, FAQ.
