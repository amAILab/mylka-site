# Ночной план доведения сайта Mylco

Дата старта: 2026-05-14, вечер

Цель: привести страницы сайта к более единому современному виду, чтобы утром можно было показать партнёрам сильную preview-версию.

## Режим

- Работать партиями примерно каждые 10 минут.
- Не слать Никите много сообщений.
- Статус — примерно раз в 3 часа или при критическом блокере.
- После каждой партии: маленькая проверка, запись прогресса, коммит при осмысленном изменении.

## Приоритеты страниц

1. Главная `index.html` — уже обновлена, держать как эталон.
2. Ключевые категории:
   - `kupit-silikon-v-moskve.html`
   - `kupit-poliuretan-v-moskve.html`
   - `epoksidnaya-smola.html`
   - `zhidkiy-plastik.html`
   - `vakuumnye-kamery.html`
   - `dobavki-k-silikonam.html`
3. Контакты и доставка:
   - `contact-us.html`
   - `dostavka.html`
4. Сервисные/производственные страницы:
   - `reversivnyj-inzhenering.html`
   - `svarochnye-raboty.html`
   - `3d-pechat-1.html`
5. Generated product pages — только безопасные шаблонные улучшения, без выдумывания цен/характеристик.

## Правила безопасности

- Не включать индексацию: сохранить `noindex,nofollow` и закрытый `robots.txt`.
- Не подключать настоящую оплату/корзину/backend без подтверждения.
- Не менять live `mylco.ru`.
- Не выдумывать цены, наличие, TDS/SDS и точные характеристики.
- Если нужны картинки, использовать существующие локальные изображения из `image/` и не тянуть чужие без проверки прав.

## Критерий готовности утром

- Главная и ключевые страницы выглядят единообразно.
- Есть понятные hero, CTA, структура выбора, карточки категорий/задач.
- Preview безопасен.
- GitHub Pages деплой успешен.
- Никите отправлена одна итоговая ссылка и краткая сводка.
